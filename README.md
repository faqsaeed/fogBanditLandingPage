# Fog Bandit Jewellery Landing Page

First-draft jewellery-store landing page for Fog Bandit ANZ, structured around PAS (Problem, Agitation, Solution) and designed for responsive conversion on desktop and mobile.

## Structure
- `index.html` — landing page content and sections
- `styles.css` — responsive design system
- `script.js` — assessment CTA behaviour
- `public/jewellery-fog-hero.png` — hero visual

## Local preview
```bash
python3 -m http.server 4173
```
Then open `http://localhost:4173`.

## Conversion flow
Primary CTA routes prospects to a jewellery security assessment form. The current first draft opens a pre-filled email to `security@banditanz.com` so no backend is required for review.
